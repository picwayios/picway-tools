PicWay Tools

Resize images

Change the width and height in pixels or percent.

This web tool has no server that receives the image file: it is opened and resized inside this browser tab.

How to use it

  1. Choose your images

    Choose up to 50 images with the box above, or drag and drop them into the box. JPG, PNG, WebP, HEIC, AVIF, BMP and TIFF files all work.

  2. Set the new size

    Type a width, a height or both in pixels, or set “Resize by” to Percentage and type a number such as 50. Leave “Keep the aspect ratio” on so the image is not stretched.

  3. Download

    Each row shows the old and new pixel size. Download each file, or take them all in one ZIP.

This tool is also online at picway.app/tools/resize-image/.
