PicWay Tools

Edit photo metadata

Change a photo’s date, time or location.

The photo file is processed inside your browser, and this page has no server that receives it. If you search for a place, the name you type is sent to OpenStreetMap’s Nominatim service. Showing the map requests map tiles around the pin from OpenStreetMap’s tile server (tile.openstreetmap.org), which tells it that approximate location.

How to use it

  1. Choose the photo

    Pick a JPG or HEIC photo. The page reads its location, date, time zone and camera fields and shows them as the original values.

  2. Change what you need

    Click the map, search for a place or type coordinates. Set a new date and time. The time zone is optional. Edit the camera, author or description if you want.

  3. Save the new photo

    Save the edited photo. The page reads the new file back and shows the location and date it now holds.

This tool is also online at picway.app/tools/edit-photo-metadata/.
