PicWay Tools

Compress images

Make images smaller, by quality or a target size.

This web tool has no server that receives the image file: it is opened and compressed inside this browser tab.

How to use it

  1. Choose your images

    Choose up to 50 images with the box above, or drag and drop them into the box. JPG, PNG, WebP, HEIC, AVIF, BMP and TIFF files all work.

  2. Pick how much to compress

    Under “Compress by”, choose Quality and move the slider, or choose Target file size and type a size such as 500 KB. To make the pixel size smaller too, pick a value under “Longest side”.

  3. Download

    Each row shows the old and new size. Download each file, or take them all in one ZIP.

This tool is also online at picway.app/tools/compress-image/.
