PicWay Tools

Image converter

Change an image to JPG, PNG, WebP or another format.

This web tool has no server that receives the image file: it is opened and converted inside this browser tab.

How to use it

  1. Choose your images

    Choose up to 50 images with the box above, or drag and drop them into the box. HEIC, JPG, PNG, WebP, AVIF, GIF, BMP and TIFF files all work.

  2. Pick the output format and settings

    Choose the format under “Convert to”. For JPG, WebP and AVIF, set the quality. For JPG and BMP, choose the background color for transparent areas. Leave “Remove location” on if you plan to share the images.

  3. Download

    Download each converted image, or take them all in one ZIP.

This tool is also online at picway.app/tools/image-converter/.
