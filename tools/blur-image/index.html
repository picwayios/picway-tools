Blur image

Pixelate, blur or black out part of a photo.

This web tool has no server that receives the image file: it is opened, edited and saved inside this browser tab.

How to use it

  1. Choose an image

    Choose one image with the box above, or drop it on it. JPG, PNG, WebP, HEIC, AVIF, BMP and TIFF files all work.

  2. Mark what to hide

    Drag across each part you want to hide. You can mark several areas, or tap Whole image. Pick Pixelate, Blur or Black box; for Pixelate and Blur, also pick a strength.

  3. Create and download

    Check the preview: it shows what will be saved. Tap Create image, then tap Download.

This tool is also online at picway.app/tools/blur-image/.
